# Release artifacts are CI-owned

The build workflow auto-increments `versionCode`, regenerates `update.json`, and
extracts release notes from the `## <version>` block in `CHANGELOG.md`. Manual
edits to `versionCode`/`update.json` are overwritten on the next release sync
(commits tagged `chore(release): sync <ver> [skip ci]`).

When this rule matches, steer the author to the human-owned surface:

- Bump `version=vX.Y.Z` in `module.prop` (must match `^v[0-9]+\.[0-9]+\.[0-9]+$`).
- Add a `## <version>` section to `CHANGELOG.md` (Keep-a-Changelog style) — the
  release-notes step depends on that heading.
- Leave `versionCode` and `update.json` for CI.
